# Royal Phoenix 3D Lab — Product Specification

## Outcome
Transform the Particle Rose fork into an independent LoPRax visual R&D web app centered on a real-time 3D royal phoenix.

## Required phases
1. Repository and asset structure.
2. Real 3D phoenix base model.
3. Web optimization path and future GLB replacement contract.
4. Browser 3D scene integration.
5. Royal cinematic materials, lighting, glow, embers, haze.
6. Particle phoenix derived from the same 3D form.
7. Motion and interaction.
8. Mobile performance tiers.
9. Lab controls for experimentation.
10. Phoenix / crimson rose / crown particle morph modes.

## Acceptance contract
- The phoenix is volumetric 3D, not a flat image plane.
- Solid, hybrid, and particle display modes are available.
- Particle targets are derived from the same procedural geometry used to build the solid phoenix.
- Rose and crown are alternate 3D particle targets.
- Mouse/touch orbit and zoom work without camera permission.
- Reduced-motion preference is respected.
- Mobile devices receive lower-cost defaults.
- The app remains static-host compatible.
- A documented adapter point allows a future artist-grade GLB to replace the procedural solid model without rewriting the particle lab.
- The original upstream project is credited.

## Non-goals for this tranche
- No integration into LoPRax-Web2.
- No backend, database, login, or paid infrastructure.
- No dependency on external image-to-3D services for the working build.
- No automatic merge to main.
